# Raptor OS - Security Edition

Raptor OS Security Edition is a specialized, privacy-first Linux distribution built on Debian 12 (Bookworm). Designed for cybersecurity professionals, network analysts, and privacy advocates, it combines an arsenal of enterprise-grade auditing tools with a Kodachi-style tactical dashboard for one-click system hardening.

## Core Features

*   **Raptor Control Center:** The heart of the OS. A unified, one-click graphical dashboard that controls your entire security posture. No terminal commands required—just click and secure.
*   **Dynamic Posture Engine:** Instantly toggle your system's exposure between three strict firewall profiles (Secure, Hardened, Lockdown) directly from the dashboard without dropping local sessions.
*   **Emergency Killswitch:** A dedicated panic button in the Control Center that instantly severs all physical and virtual network interfaces at the hardware level to prevent data leaks.
*   **Curated Security Toolkit:** Pre-configured environments for reconnaissance, digital forensics, reverse engineering, web security, and network analysis, all organized in a clean, categorized application menu.

## Getting Started

### Live Boot vs. Installation
Raptor OS Security Edition can be run entirely from a USB drive as a Live OS, ensuring no trace is left on the host machine. Alternatively, you can use the built-in Calamares graphical installer to permanently install the OS to your hard drive.

### The Raptor Control Center
Upon booting into the desktop, your primary tool is the **Raptor Control Center**. From this single dashboard, you can:
1. **Monitor Status:** View real-time feedback on your active firewall rules and network status.
2. **Shift Posture:** Click to switch between **Secure** (standard privacy), **Hardened** (strict port filtering), or **Lockdown** (loopback only) modes.
3. **Engage Killswitch:** Instantly kill all network traffic in an emergency with the click of a button.
